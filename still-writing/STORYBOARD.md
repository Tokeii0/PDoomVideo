# 《还没写完》 分镜 / Storyboard

## 核心想法

一个 Q 版的小小创作者（“我”），白天上班，午夜下班。摘下工作牌之后，夜晚才属于她自己。一个会发光的小念头（一颗长着脸的小星星）跟着她回家，被她一圈一圈画进草稿本，最后变成了粉色双马尾的小看板娘 **桃桃**，住在她屏幕的角落里。

副歌是她“还没写完”的倔强：不让别人替她**落款**（一枚板着脸的玉石印章总想来盖“完”）、不急着**圆满**（她和桃桃坐在一弯月牙上，故意不把它画圆）、给**冷冰冰**的灰色城市画上柔软的颜色。桥段里她累了，热一碗凉掉的面，被猫和桃桃照顾。最后一次副歌，她穿着睡衣、披着被子，和桃桃坐着纸飞机飞过夜空，把城市一片一片涂成暖色。结尾关掉屏幕说晚安，天亮了，接着写，接着喜欢。

**每个镜头都要有事发生**：角色在做事、东西在变化、镜头在动。节拍 100 BPM（一拍 0.6 s，拍点在 `0.156 + n × 0.6` s），主歌温柔，副歌更有弹性。

**少写字。** 画面讲故事。整支 MV 只用几次拟声字（“叮”“啪”“噗”），标题只出现在开头和结尾。卡拉 OK 歌词条已经显示歌词，画面里不要重复歌词。

## 角色

| 角色 | 造型 | 作用 |
|---|---|---|

| **月牙** `moonFace()` | 睡眼惺忪的弯月。 | “也不急着圆满”。 |

## 贯穿全片的东西

- **她的房间**（`room()` 正面、`roomReverse()` 反打、`deskTop()` 俯拍桌面）：雨夜的窗、城市光斑、台灯、显示器、草稿本、桃子汽水罐、马克杯、小盆栽、软木板上的便利贴、团子的粉色垫子。几乎一半的镜头发生在这里，所以房间永远长一个样。
- **桃子汽水罐**：第一段主歌里冰凉的罐子，之后一直放在桌上；第二次副歌她用它给水泥缝里的小芽浇水。
- **一条线**：她写下的“这一行”。每次副歌结尾都是她写下一行发光的线。
- **颜色走向**：开头像封面照片一样近乎黑白的蓝灰 → 办公室冷白 → 夜晚靛蓝 + 台灯暖黄 → 副歌粉、桃、奶黄、薄荷 → 桥段深蓝与微波炉的暖光 → 最后副歌整座城被涂成暖色 → 结尾清晨桃色。
- **转场**：章节之间用翻页（纸的主题）、晕染水彩、淡入淡出；章节内部靠动作带过去（推进窗户、推进本子、笔尖发光变白、泡泡破掉）。
